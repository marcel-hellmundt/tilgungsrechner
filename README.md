# Tilgungsrechner

Minimalistischer Tilgungsrechner als statischer One-Pager (React + Vite + TypeScript). Alle Berechnungen laufen im Browser, es gibt kein Backend.

## Entwicklung

```bash
npm install
npm run dev      # Dev-Server
npm run build    # Produktions-Build nach dist/
npm run preview  # Build lokal ansehen
npm run lint     # oxlint
```

Die App ist für GitHub Pages unter `/tilgungsrechner/` konfiguriert (`base` in `vite.config.ts`).
